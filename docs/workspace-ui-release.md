# LocalLink 记录工作台更新

本次沿用 2.4.0 版本与既有签名，安装包单独保存在 `dist/workspace-ui`，不替换之前的交付文件。

## 变更

- 灰白内容区、石墨桌面导航、蓝色操作按钮；手机固定主页、发送、记录、设备四页。
- 记录支持内容/文件名/设备搜索，六种分类、时间或大小排序、日期分组与每页 20 条。
- 长文本提供自动换行摘要和独立全文阅读；文件名称、发送端、接收端分层展示。
- 文件缺失有明确提示；常用阅读、预览和保存靠前，删除集中到详情并要求确认。
- 相同数据轮询不重复重建记录列表；请求串行刷新、失败时保留已有内容并提示连接状态。
- 修正旧记录缺失校验值导致的渲染异常、文本预览标题重复转义、页面入口及扫描按钮异步状态问题。

## 验证

- JavaScript 语法检查、UI 模型与连接状态两套测试通过。
- Python unittest 19 项通过。
- Android JVM 单元测试 13 项通过，Debug APK 构建成功。
- Windows 单文件 EXE 构建成功。
- 浏览器检查桌面 1280px、手机 390px；搜索、长文本阅读、包含特殊字符的 TXT 预览验证通过。
- 独立收尾审查：跳转焦点、手机分类布局、文本文件标签、进度动画、桌面边界共五项均已解决。

## 使用与限制

两端都更新后使用新界面；查看远端主机时，页面资源及记录来自该主机，因此旧主机仍可能显示旧界面。
Android 包为开发签名 Debug 构建，不是应用商店发布包。若覆盖安装提示签名不一致，请先备份数据并核对旧包签名，不要直接卸载。
本轮未用真实手机完成安装、局域网互传与系统文件打开验证；APK 编译成功不等同于真机端到端验证。Office 预览和安装包打开仍受已有转换器与系统应用能力限制。
